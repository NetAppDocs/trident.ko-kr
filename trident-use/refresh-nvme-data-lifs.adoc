= NVMe 데이터 LIF 새로 고침
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
백엔드를 다시 생성하거나 Trident를 다시 시작할 필요 없이 게시된 NVMe 볼륨이 추가, 제거 또는 새 주소가 할당된 LIF를 사용할 수 있도록 NVMe 데이터 LIF 새로 고침을 활성화합니다.



[[overview]]
== 개요

ONTAP SAN 백엔드를 추가하면 Trident는 SVM에 대한 NVMe 데이터 LIF를 검색합니다. 기본적으로 Trident는 백엔드를 다시 추가하거나 Trident를 다시 시작할 때까지 해당 LIF 세트를 유지합니다.

Trident가 실행 중일 때 NVMe 데이터 LIF를 새로 고치려면  `enableDataLIFRefresh`을(를)  `true`(으)로 설정합니다. 그러면 게시된 NVMe 볼륨은 추가, 제거 또는 새 주소가 할당된 LIF를 사용합니다.

이 옵션은 설치 매개변수이며 백엔드 구성 매개변수가 아닙니다. 기본적으로 비활성화되어 있습니다.

NVMe 데이터 LIF 새로 고침 기능은 Trident 26.10 버전부터 사용할 수 있습니다.

이 기능은 다음 항목에 적용됩니다:

* `ontap-san`(통합 ONTAP에서  `sanType: nvme`와(과) 함께).
* `ontap-san` ASA r2에서 NVMe/TCP를 사용합니다.


[CAUTION]
====
모든 데이터 LIF를 동시에 제거하거나 교체하면 시스템에 장애가 발생할 수 있습니다. 모든 데이터 LIF를 제거하거나 교체할 계획이라면 데이터 액세스가 중단되지 않도록 먼저 대체 LIF를 설치해야 합니다.

====


[[enable-nvme-data-lif-refresh]]
== NVMe 데이터 LIF 새로 고침 활성화



[[trident-operator]]
=== Trident 운영자

새로 설치하는 경우  `TridentOrchestrator` spec에서  `enableDataLIFRefresh`을 설정하십시오.

[source, yaml]
----
apiVersion: trident.netapp.io/v1
kind: TridentOrchestrator
metadata:
  name: trident
spec:
  namespace: trident
  enableDataLIFRefresh: true
----
매니페스트를 적용합니다:

[source, console]
----
kubectl apply -f tridentorchestrator_cr.yaml
----
기존 설치의 경우  `TridentOrchestrator`을(를) 패치하십시오:

[source, console]
----
kubectl patch torc trident --type=merge -p '{"spec":{"enableDataLIFRefresh":true}}'
----
적용된 값을 확인하십시오:

[source, console]
----
kubectl get torc trident -o jsonpath='{.status.currentInstallationParams.enableDataLIFRefresh}'
----


[[helm]]
=== 헬름

새 설치의 경우 Helm 값을 설정하십시오:

[source, console]
----
helm install trident netapp-trident/trident-operator \
  --namespace trident --create-namespace \
  --set enableDataLIFRefresh=true
----
기존 Helm 설치의 경우, 값을 활성화하여 릴리스를 업그레이드하십시오:

[source, console]
----
helm upgrade trident netapp-trident/trident-operator \
  --namespace trident \
  --reuse-values \
  --set enableDataLIFRefresh=true
----
Helm 값 파일에서  `enableDataLIFRefresh: true`을 설정하고  `-f <values-file>`을 사용하여  `helm upgrade`에 전달할 수도 있습니다.



[[tridentctl]]
=== tridentctl 을 선택합니다

새 설치의 경우  `--enable-datalif-refresh` 플래그를 사용하십시오:

[source, console]
----
tridentctl install --enable-datalif-refresh -n trident
----
기존  `tridentctl` 설치에서 옵션을 활성화하려면 Trident를 제거하고 플래그를 사용하여 다시 설치하십시오. 제거하기 전에 link:../trident-managing-k8s/uninstall-trident.html["Trident를 제거합니다"]의 주의 사항을 따르십시오.

[source, console]
----
tridentctl uninstall -n trident
tridentctl install --enable-datalif-refresh -n trident
----

NOTE:  `--enable-datalif-refresh` 플래그는 설치 옵션이며  `tridentctl install --help`에 표시되지 않습니다.
